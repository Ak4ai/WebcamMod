# Webcam Mod - Forward Port by ak4ai

**Forward port para Minecraft 1.21.8** | Arquivo de saída: `webcammod-forward-port-by-ak4ai-1.0.jar`

---

## 🎯 Sobre este Fork

Este é um **forward port** do mod original [WebcamMod](https://github.com/Lichcodes/WebcamMod) criado por **[Lichcodes](https://github.com/Lichcodes)**.

### Portado por: **ak4ai**
- GitHub: [@ak4ai](https://github.com/ak4ai)
- Este port atualiza o mod para funcionar com versões mais recentes do Minecraft (1.21.8)
- Mantém todas as funcionalidades originais com compatibilidade atualizada

---

## ⚠️ Aviso (Disclaimer)

Este mod **não deve ser usado em servidores públicos**, apenas com pessoas de confiança. É relativamente fácil enviar um payload malicioso que pode crashar seu jogo (ou pior!). **Use por sua conta e risco.**

Este mod não está pronto para produção. O criador original fez para um vídeo do YouTube: https://youtu.be/pRvUX16k6yw

---

## ✨ Funcionalidades

Adiciona o feed da sua webcam ao seu player e exibe em tempo real. Funciona muito bem em LAN, e foi testado em servidor online com dois jogadores.

**Este é um mod server/client**, então precisa ser instalado em ambos.
